Dans les synthèses (talks, posters, synthèse générale) écrites pour Boris dans le Google Doc, ne mettre QUE le contenu scientifique : contexte, méthodes, résultats chiffrés, conclusions, références (DOI/PMID). Interdits : numéros/horodatages de photos, heures et créneaux, « illisible », « lecture incertaine », sections Limites/Journal, remerciements. Forme attendue : note scientifique structurée (Contexte → Méthodes → Résultats → Conclusions → Références → Publications liées hors talk), pas un compte rendu diapo par diapo. Figures : seulement celles qui complètent le propos (0–4 par talk, ≤ 1 par poster), jamais « toutes les photos ».

**Why:** Boris l'a exigé explicitement le 2026-09-28 après avoir vu la première version (qui citait photos et heures), puis a précisé pour les figures « pas toutes les photos, les figures complémentaires ».

**How to apply:** la traçabilité (photo source, lecture incertaine, écarts talk/publication) reste dans les fichiers locaux `synthese_complete.md` ; le Doc reçoit `synthese_scientifique*.md`. Données « Do not post » : incluses sous le bandeau `> ⚠ Données non publiées — ne pas diffuser` (décision de Boris). Voir [[eacr-google-doc]].
